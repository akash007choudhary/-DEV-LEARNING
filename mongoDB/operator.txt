1. Comparison Operators

Used when comparing values.

Operator	Meaning
$eq	    Equal to
$ne	    Not equal to
$gt	    Greater than
$gte	Greater than or equal
$lt 	Less than
$lte	Less than or equal
$in	    Matches any value in a list
$nin	Doesn't match any value in a list

2. Logical Operators

Used to combine multiple conditions.

Operator	Meaning
$and	    Both/all conditions must be true
$or     	At least one condition must be true
$not	    Negates a condition
$nor    	None of the conditions should be true



//examole 
db.student.find({
    $or: [
        { age: { $gt: 25 } },
        { marks: { $gt: 90 } }
    ]
})

Find students who are either:

age > 25
OR marks > 90
