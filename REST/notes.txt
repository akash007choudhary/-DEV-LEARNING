REASON
**CORS (Cross-Origin Resource Sharing)** is a security mechanism that controls whether a web application from one origin can send requests to a server on another origin. In our case, **Hoppscotch (`https://hoppscotch.io`)** was trying to access our Express API at **`http://localhost:3000`**, which are different origins, so the browser blocked the request. We solved this by installing the `cors` package and adding `app.use(cors())` to Express. You need CORS when your **frontend/client and backend are running on different origins**, such as React on `localhost:5173` and Express on `localhost:3000`.
