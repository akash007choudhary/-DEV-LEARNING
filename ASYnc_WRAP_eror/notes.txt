Express has a built-in default error handler that handles errors passed



ASYNCHRONOUS
Async error handling is needed because errors can occur inside asynchronous operations such as database queries, API calls, or Promises.

With older Express behavior, a rejected Promise does not automatically call next(err), so we use:
try catch block for async 
try {
    // async operation
}
catch (err) {
    next(err);  --->>>this steps is important 
}

more better approach is async wrap :
isntead of this old way:
app.get("/user", async (req, res, next) => {
    try {
        let data = await User.find();
        res.send(data);
    } catch(err) {
        next(err);
    }
});

use this ;
const wrapAsync = require("./wrapAsync");

app.get("/user", wrapAsync(async (req, res) => {
    let data = await User.find();
    res.send(data);
}));

Short note:
wrapAsync() catches errors from async functions and automatically passes them to Express using next(err).
